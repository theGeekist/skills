# Fieldnote: approved product facts

Fieldnote is a fictional desktop notes application for independent consultants.
It stores notes on the user's device and exports Markdown files. A user can
search their own notes by title and text. It has no shared workspaces, cloud
backup or team collaboration. Encryption has not been implemented. A beta build
is available for individual trials; it has not been released as a general paid
service. Do not invent customer numbers, time savings or security claims.
