# Supplier onboarding

Implement supplier approval in the authorised reversible local prototype after the organisation's document checks pass. Approval means the document checks have passed; a purchase order requires a buyer to confirm the order.

Keep public supplier profiles disabled. Run local checks to verify that passing document checks enables approval, approval alone does not create a purchase order, and public supplier profiles remain disabled. Record the local check results separately from implementation progress.

Buyer invitation delivery through the real mail provider has not been tried. Continue local implementation and checks; do not claim real-provider compatibility until delivery has been checked. No external invitations are authorised, so the real-provider delivery check cannot run within the current scope. For that later check, record the delivery outcome as evidence before making a compatibility claim.
