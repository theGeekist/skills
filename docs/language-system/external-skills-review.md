# External skill source evaluation

This review covers every repository and reference raised in the product-narrative discussion. The 26 selected skills are compiled as separate packages. Their upstream `SKILL.md` files and selected dependencies are copied verbatim. Geekist adds only catalogue/interface metadata, the original licence notice, attribution records and locally supplied plugin icons.

## Evaluation scope

The evaluation considered each skill's stated task, proximity to product communication and developer adoption, overlap with Geekist's existing skills, installation structure, supporting files and licence. This is a source and structure review. The skills have not been benchmarked by generating and judging outputs against Geekist repositories. A compelling claim in an upstream README remains that author's claim.

The source links below are pinned to the commits included in this collection. Each copied package has a `references/GEEKIST-UPSTREAM.md` file linking its exact source path and commit, plus the full upstream `LICENSE.upstream`.

### Why these belong in the same collection

The sources cover distinct jobs: positioning establishes what a product means in its market; storytelling shapes how that meaning becomes memorable; README and launch skills turn it into a developer-facing experience; developer-marketing playbooks address adoption paths; writing and editing skills improve prose mechanics. There is overlap, especially in README writing, copywriting, humanisation and messaging. Keeping each source package intact preserves its own method and gives us real options to compare later.

The import does not make every skill a recommended first choice for every task. The catalogue exposes them separately with each original trigger description. Geekist's own general writing, marketing, technical-documentation and review descriptions have also been widened so ordinary requests can reach them without requiring the user to name a skill or use a narrow trigger phrase.

## Licence handling

Each selected source repository was checked for an MIT licence before copying. Every imported skill has the original repository's full MIT notice in `LICENSE.upstream`, preserving the upstream copyright holder and permission terms. The required source and attribution are recorded per package. Geekist's repository licence continues to apply to Geekist-authored files and does not replace upstream notices.

## Limitations and next evaluation

This is a structural and source review, not a quality benchmark. The skills have not been tested against PulseGraph or other Geekist repositories, and their generated README or product narrative has not been compared to current Geekist writing. Several source packages contain scripts or external workflow instructions. Those scripts were copied as source and were not executed as part of this evaluation.

A useful next comparison is a small, observable trial with one real product: the same verified product facts, repository context and target reader; outputs from a few relevant skills; then review for positioning accuracy, intrigue, specificity, visual demonstration and technical trust. The skills should remain individually available regardless of the eventual trial results.
