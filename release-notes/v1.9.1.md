# Geekist Skills v1.9.1

This release adds a dedicated **ChatGPT plugin upload archive**. The previous generic GitHub source ZIP includes the entire repository, including marketplace configuration and development files, and can trigger "Expected a single plugin archive" when submitted through ChatGPT's Personal plugin uploader.

## ChatGPT installation

Download **geekist-skills-chatgpt-v1.9.1.zip** from this release. It has one plugin root containing `.codex-plugin/plugin.json` and the complete `skills/` directory, including all 13 skills and their references.

In ChatGPT web, use Plugins → Personal → Add plugin and select that archive. The ordinary `geekist-skills-v1.9.1.zip` remains a repository source archive rather than an uploader package.

## Packaging and checks

The new `scripts/package-chatgpt-plugin.py` creates a minimal, deterministic ZIP, and packaging tests verify exact file membership, one manifest, skill count, reference bytes, archive integrity and reproducibility.

No skill guidance has been changed in this patch.
