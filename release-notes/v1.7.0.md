# Geekist Skills v1.7.0

This release connects the collection’s public presentation to its research and makes the eleven workflows easier to discover. The README follows a project-queue example through the writing problem, with direct routes to practical examples and the underlying sources.

## Writing guidance

The review skill includes eight contextual editorial patterns with stable identifiers and locally authored examples. Its final source comparison checks additions and omissions, including changes to permissions or status. It also establishes the supplied voice and edits document structure before individual sentences.

Five drafting skills include an explicit final editing pass: implementation tasks, architecture decisions, technical documentation, marketing and interface content. These changes adapt useful practices from the compared writing skills while preserving project authority and deliberate voice.

## Research and discovery

The competitor comparison identifies useful practices and links their implementation. Each skill overview explains its foundations through the canonical presentation catalogue. The collection also includes generated skills.sh groupings and updated plugin descriptions, with `https://geekist.co/skills` as its landing-page destination.

The backend and frontend architecture rules retain their existing technical meaning. Activation scopes and the stable plugin identity are unchanged. Directory presentation configuration is included; directory indexing and native client activation remain separate observations.

## Installation

```sh
npx skills add https://github.com/theGeekist/skills/tree/v1.7.0
```

Choose the required skills and target agent. This portable installation command is separate from ChatGPT plugin registration.
