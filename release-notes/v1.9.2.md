# Geekist Skills v1.9.2

This patch release corrects the dedicated ChatGPT plugin archive so it carries the repository's MIT licence notice with the skills it distributes.

## ChatGPT plugin archive

The archive now includes the root `LICENSE` alongside `.codex-plugin/plugin.json` and the complete `skills/` tree. The packaging test requires the licence file and verifies the archive's exact contents and bytes.

Download **geekist-skills-chatgpt-v1.9.2.zip** for ChatGPT's Personal → Add plugin upload. The regular source ZIP remains the full repository archive.

## Other installations

Install the versioned collection with:

```sh
npx skills add https://github.com/theGeekist/skills/tree/v1.9.2
```

No skill guidance changed in this patch.
