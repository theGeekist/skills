# Geekist Skills v1.5.0

Eleven portable skills now share one clear writing baseline, with focused entry points and references loaded for the work at hand.

## Included workflows

- Backend and frontend architecture, with smaller decision cores and local supporting references.
- Project terminology discovery and maintenance.
- Implementation tasks and worker handoffs.
- Architecture decision records.
- Technical documentation.
- Marketing content.
- Interface labels, states, progress and errors.
- Cross-artefact language review.
- Actionable uncertainty: turn evidence gaps into bounded next steps while preserving genuine blockers.
- An explicit compatibility chooser for older `write-project-content` callers.

Every skill embeds the same canonical 144-word baseline. The collection includes context-aware terminology checks, reference drift checks, selected advisory prose rules and an optional Codex Stop adapter. Installing a skill does not install hooks or alter global agent instructions.

Both architecture playbooks preserve their boundary rules. Their main files shrink from 2,411 to 907 words for backend and from 2,198 to 979 for frontend, including metadata. Detailed rules remain available through concern-specific references.

## Validation and compatibility

All eleven packages pass the portable Agent Skills validator. The suite has 57 checks, including an optional Vale integration exercised locally. Three catalogue trials each selected the expected purpose for twelve ordinary requests. Observed marketing and ADR trials loaded the relevant skills and references and met their requested output lengths.

These results establish package shape, catalogue discrimination and observed resource use. Actual discovery and implicit activation remain client-specific adoption checks. CLI, desktop and cloud surfaces have separate compatibility records.

The release contains source archives, checksums and a manifest identifying the release commit, tree and skills. Research, lifecycle guidance, evaluation records and the recommendation pipeline are included. Private project evidence remains separate.

## Install

```sh
npx skills add https://github.com/theGeekist/skills/tree/v1.5.0
```

Choose the skills and intended agents in the installer. For a canonical local checkout, clone the `v1.5.0` tag and use `scripts/link-local.sh --client all --dry-run` before applying links. Existing conflicting entries are preserved unless deliberately adopted.
