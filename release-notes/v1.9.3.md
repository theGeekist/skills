# Geekist Skills v1.9.3

This patch keeps evaluation material out of downloadable production archives.

## Release archives

The source ZIP and tarball now exclude the repository's `evaluations/` directory, including evaluation hash manifests and captured evaluation outputs. The evaluation records remain in the repository for contributors and reviewers. The ChatGPT plugin ZIP continues to contain only its plugin manifest, MIT licence notice and installable skills.

The generated `SHA256SUMS` file covers the release archives and release manifest only. It does not contain evaluation hashes and remains a separate release asset for download verification.

Install the pinned collection with:

```sh
npx skills add https://github.com/theGeekist/skills/tree/v1.9.3
```

No skill guidance changed in this patch.
