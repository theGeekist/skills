# Geekist Skills v1.8.0

This release makes existing Geekist writing guidance easier to invoke from natural requests without turning general writing into a document-template system.

## General writing

`write-project-content` now covers reports, research notes, investigation findings, meeting summaries, progress updates and explanatory prose where no narrower specialist fits. It remains an explicit workflow chooser but no longer disables implicit invocation in Codex metadata. Specialists remain directly selectable without requiring the general writer.

## Specialist discovery

Skill descriptions now recognise technical investigations and spike reports, polishing existing prose, informal technical decision rationales, actionable follow-ups and broader audience-facing content. Shared writing principles, project authority and style remain intact.

Selection fixtures include ordinary prompts for general reports, technical research, rewrites, informal decisions and non-writing requests. Packaging and metadata checks remain separate from actual runtime activation, which depends on the client.

## Installation

```sh
npx skills add https://github.com/theGeekist/skills/tree/v1.8.0
```

Select the desired target agents and skills. ChatGPT plugin installation remains a separate process.
