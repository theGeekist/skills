# Geekist Skills v1.10.0

## Added

- Add 26 independently installable skills from 14 MIT-licensed upstream repositories, preserving their original instructions and selected supporting files.
- Preserve each upstream repository's full MIT licence notice and pin its attribution to the included commit.
- Add a candidate-by-candidate evaluation, including sources not copied because a reusable licence was unavailable or because the reference was an article rather than a skill.
- Widen five Geekist writing skill descriptions so ordinary writing and documentation requests can reach them without narrow trigger phrasing.
- Support block-style YAML activation descriptions in the skill catalogue generator and preserve upstream-supplied OpenAI interface metadata.
- Expand catalogue and plugin metadata to 39 skills.

## Evaluation scope

This release records a structural and source review. It does not claim comparative output testing of imported skills.
